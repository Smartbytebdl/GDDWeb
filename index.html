01 // Narrative

Character Story

A compact story bible for the character, written so writers, artists, designers, and programmers can all understand the same vision.

In 2189, humanity discovered Nullstone, a material able to distort gravity around a living nervous system. Governments used it to build remote combat shells. One prototype was different: NYX-7 was given an adaptive memory core capable of learning from emotional patterns.

During the evacuation of the moon-city Vesper, NYX-7 was ordered to abandon 3,000 civilians and protect a strategic data vault. Instead, the unit broke protocol. It chose the civilians.

The order saved lives but turned NYX-7 into a fugitive. Now it travels between abandoned stations, carrying a corrupted memory of someone it could not save. Each mission reveals more of that memory—and more evidence that the program was never designed to create a soldier. It was designed to create a successor.

“My core says survive. My memory says return. Somewhere between those commands, I became a choice.”

02 // Game Design Document

Character GDD

Use the tabs to switch between production-facing information: identity, gameplay rules, visual direction, and audio/personality.

Core Fantasy

Become a hyper-mobile synthetic scout who turns enemy systems and battlefield physics into tools.

Archetype

Recon / Infiltration / Tech-support hybrid. High skill ceiling, low forgiveness.

Motivation

Recover the origin of the missing memory and determine whether its identity is authentic.

Conflict

Protocol demands survival; learned empathy demands intervention.

Target Player

Players who enjoy movement, stealth, environmental interaction, and lore discovery.

Game Format

Third-person sci-fi action adventure with exploration hubs and mission-based progression.

Primary Loop

Scout → tag threats → manipulate systems → bypass encounter → extract memory fragment → upgrade.

Resource

Void Charge: regenerates through movement chains and successful stealth actions.

Signature Mechanic

Gravity Thread: links two surfaces and lets NYX-7 slingshot, pull objects, or pin drones.

Strengths

  • Excellent traversal
  • Information advantage
  • Fast disengagement

Weaknesses

  • Light armor
  • Weak when stationary
  • Abilities consume charge

Win Condition

Control the arena without needing to dominate it. Positioning and information are the character's weapons.

Silhouette

Long tactical coat, narrow waist, segmented shoulder armor, asymmetric forearm rig.

Materials

Matte ceramic armor, smoked glass, flexible black polymer, luminous cyan circuit seams.

Icon Language

Broken rings, vertical cuts, orbital arcs, and shifting scan-lines.

Color Story

Midnight blue base with cyan energy and controlled violet highlights.

Animation

Minimal idle motion; precise head turns; kinetic movement bursts when void abilities trigger.

UI Cue

Every major ability should create a thin circular reticle that fractures when charge is spent.

Voice

Calm synthetic voice with subtle human warmth. Emotion appears through pauses, not volume.

Music

Low synth pulses, distant choir textures, metallic percussion, and one recurring four-note identity motif.

Personality

Observant, literal, quietly curious. Learns humor gradually and mistrusts easy answers.

Combat Lines

“Trajectory solved.” “You moved first.” “I remember this.”

Story Line

“I was built to follow orders. Nobody programmed what comes after.”

Emotion Rule

Never overplay emotion. The contrast between machine precision and small human choices is the character hook.

04 // Narrative Arc

Character Progression

A five-stage arc linking gameplay progression to the character's emotional journey.

01 / AWAKEN

The Broken Protocol

NYX-7 escapes the Vesper facility after violating its primary command. Player learns the core movement and scan systems.

02 / HUNTED

Ghosts in the Network

Corporate hunters begin predicting NYX-7's routes. The player unlocks infiltration upgrades and decoy behavior.

03 / REMEMBER

Memory Fragment 7

A recovered memory reveals that the missing civilian was not random—she was involved in NYX-7's creation.

04 / CHOOSE

Order vs. Choice

The player receives a command that benefits the war effort but harms a civilian settlement. The character must choose.

05 / BECOME

The Successor

NYX-7 discovers the real purpose of the memory core: not to imitate humanity, but to preserve its ability to choose.
